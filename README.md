El siguiente proyecto hace referencia al desarrollo del siguiente sistema: Sistema de Inventario y Ventas 

Este tendra los modulos de compras y ventas y por ello entonces se podra administrara el inventario por medio de un control de inventario. Dicha gestion de inventario administrara las entradas de productos (compras) salida de productos (ventas) y se podra generar reportes de invntarios por stock.

Sistema desarrollado por el aula 3DS.
